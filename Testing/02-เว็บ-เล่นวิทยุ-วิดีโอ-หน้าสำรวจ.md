## 4. API ใหม่ (API-DIR-GEO)

ยิงด้วย `curl --cacert <root CA> https://api.192-168-1-37.sslip.io/...` โดยไม่ต้องเข้าสู่ระบบ ทั้งสองคำขอนับรวมโควตา 60 ครั้งต่อนาทีต่อเครื่อง

| รหัส | คำขอ | ผลที่ต้องได้ |
|---|---|---|
| API-DIR-GEO-001 | `GET /v1/directory/radio?hasGeo=true&limit=10` | 200 ทุกสถานีมี `geo.lat` (−90..90) และ `geo.lon` (−180..180) เป็นทศนิยมไม่เกิน 2 ตำแหน่ง และไม่มีสถานีที่ 0,0 |
| API-DIR-GEO-002 | `GET /v1/directory/radio?limit=10` | 200 ไม่มีฟิลด์ `geo` เลย (รูปแบบเดิมของแอป) |
| API-DIR-GEO-003 | `GET /v1/directory/radio?hasGeo=yes` | 400 `VALIDATION_FAILED` field `hasGeo` |
| API-DIR-GEO-004 | `GET /v1/directory/radio?hasGeo=true&country=TH` | 200 เฉพาะสถานีไทย |
| API-DIR-GEO-005 | `GET /v1/directory/radio/countries` | 200 `countries` เรียงจากมากไปน้อย ทุกตัวเป็นรหัส 2 ตัวพิมพ์ใหญ่และ `stations ≥ 1` มี `attribution` และ header `Cache-Control: public, max-age=3600` |
| API-DIR-GEO-006 | `GET /v1/directory/radio/countries?x=1` | 400 `unknown_field` |
| API-DIR-GEO-007 | สถานีที่ staff บล็อกไว้ใน /admin/directory | ไม่ปรากฏในผลของ hasGeo=true เช่นกัน |
