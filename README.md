# TuneDeck

In-car internet radio app (Flutter + native CarPlay/Android Auto) with a NestJS backend and Next.js web console.

The specification lives in [Docs/](Docs/README.md) (revision 0.2). Work is split per [Docs/19-Claude-Codex-Collaboration.md](Docs/19-Claude-Codex-Collaboration.md): Claude owns `services/api`, `apps/console` and `services/worker`; Codex owns `apps/mobile` and the shared contract/bootstrap (COL-00).
